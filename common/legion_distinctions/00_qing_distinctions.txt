# 00_qing_distinctions.txt — QING LEGION DISTINCTIONS (Phase 4d).
#
# Legion distinctions CANNOT be gated in their definition (no allow/enable/potential/trigger —
# oracle-verified). They are PASSIVE REWARDS granted by the add_distinction effect. So these are
# defined globally and GRANTED only to Qing legions via the Ministry-of-War grant path (Part G):
# the on_legion_raised on_action (00_specific_from_code.txt) awards ONE of these to a freshly-
# raised CHI legion, the tier chosen by the 兵部's standing (qing_min_perf_war) — a well-run War
# Ministry earns the elite corps' distinctions, a bare one only the basic Green-Standard mark.
# That IS the "tied to the Ministry of War" the user asked for: the martial ministry's competence
# literally decides which distinction the army earns.
#
# SCOPE RULES (verified against TI 00_default.txt):
#   commander = { }  — character modifiers (loyalty_gain_chance_modifier ...).
#   unit = { }       — cohort modifiers. Unit-TYPE keys are prefixed (heavy_infantry_offensive,
#                      light_cavalry_offensive, archers_defensive ...) BUT terrain bonuses are
#                      BARE (mountain_combat_bonus, desert_combat_bonus, forest_combat_bonus ...),
#                      NOT unit-prefixed — the distinction applies them across the legion.
#   legion = { }     — legion-wide keys (siege_ability, siege_engineers ...).
# Icons = base-game phalera_* sprites (referenced bare; imp19c is an I:R total conversion on the
# base game, so they resolve without shipping art). 1763-appropriate: smoothbore/matchlock
# firepower, NO rifling.
#
# TAB indentation throughout.
########################################################################
