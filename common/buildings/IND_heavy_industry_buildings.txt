# WORLDWIDE early-industrial buildings, fleshing out the coal→iron→steel→power
# chain the mod previously modelled only through the abstract IND_industrial_
# estate. These carry the neutral IND_ prefix (like IND_industrial_estate /
# IND_resource_gathering_operation) so ANY nation can industrialise, not just the
# Qing — the China-specific named works (Hanyang, Jiangnan, Kaiping…) live in
# qing_industry_buildings.txt and are the flavourful variants of the same chain.
#
# INDUSTRY MODEL (user decision 2026-07-27): PARALLEL, SAME CAPACITY GATE. Each
# factory competes for the province's industry capacity through the SAME proven
# gate the estate uses — `INDUSTRY_province_industry_capacity > num_of_IND_
# industrial_estate` — rather than the unproven negative-building-slot mechanic.
# They do NOT consume the estate; they draw on the same capacity pool.
# add_building_level still bypasses allow for any event/seed path.
#
# All modifier keys verified building-scope; VALUES on the proven scale
# (local_monthly_civilization 0.01..0.1, etc.). NOT 1763-seeded — tech-gated.
# BOM / UTF-8, matching common/buildings/ siblings.
