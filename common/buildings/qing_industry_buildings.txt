# qing_industry_buildings.txt — [buildings-research 2026-07-27] the CHINA-SPECIFIC
# named works of the Self-Strengthening / early-industrialization era (洋務運動,
# and the 1763-start's earlier divergence via se_QING_EARLYINDUS.txt). These are
# the flavourful Chinese variants of the generic IND_ chain (IND_heavy_industry_
# buildings.txt): the real historical enterprises of 李鴻章 / 張之洞 / 左宗棠 /
# 盛宣懷. The generic worldwide buildings model the template; these model China's
# actual factories, and carry the qing_ prefix + a Chinese-culture gate.
#
# INDUSTRY MODEL: PARALLEL, SAME CAPACITY GATE (user decision 2026-07-27) — the
# heavy works compete for province industry capacity via the same proven gate as
# IND_industrial_estate. The modern SCHOOLS / TELEGRAPH / BANK are civil, not
# industrial-capacity, so they omit that gate (like the shuyuan / customs house).
#
# NOT 1763-seeded — every one is tech-gated to the modern era. The generic
# qing_selfstr_wonder_building (qing_selfstr_buildings.txt) remains the earned
# capstone; these are the buildable institutions beneath it. All modifier keys
# verified building-scope; VALUES on the proven scale. BOM / UTF-8.
########################################################################
