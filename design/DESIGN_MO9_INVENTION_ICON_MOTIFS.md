# MO#9 — invention-icon subject motifs — design (2026-07-29)

Branch: merge-overnight (worktree imp19c-mo). Boot-test #9: the 272 invention icons (generated by
tools/gen_invention_icons.py) all render as a hash-driven spoke/rosette = "generic graph/node" look,
not subject-appropriate art. Fix = give the generator a MOTIF VOCABULARY keyed off each invention's
meaning, drawn on the existing tinted disc. Pipeline (icon_override->GFX_<key> spriteType) UNCHANGED;
only emblem() is replaced by a motif dispatcher.

## Style basis (upstream)
Invictus + TI ship NO bespoke per-invention icon art (icon_override used ~8x, only shared engine
sprites gw_icon/war). BUT both use a clear "one flat emblem per object, file-per-key" idiom for
per-object icon SETS (gfx/interface/icons/military_traditions/, /deities/) — a simple legible
silhouette on a tinted disc. That is the target grammar (matches imp19c's own traditions/deities/
tradegoods icon families), NOT a hash rosette and NOT painterly art.

## Vocabulary: 38 motifs, drawn with PIL primitives at 200x200 (PX*S) then LANCZOS->50
Each motif is a function motif_<name>(d, tint, c, r) using only line/polygon/ellipse/arc/pieslice,
drawn AFTER disc(d, base_col), tinted tint = min(255,x+90) per channel. Names + draw-recipes:
war_banner, rifle, cannon, machine_gun, revolver, grenade, sailing_ship, anchor(reserved), vial_flask,
compass_dividers, book_scroll, rail_track, jar, loom_thread, hammer_anvil, bridge_canal, kiln_flame,
cogwheel, telegraph_pole, lightning_bolt, steam_engine, seal_stamp, coin_ingot, envelope_letter,
scales_of_justice, printing_press, camera_lens, theatre_mask, telescope, fossil_spiral, plough_wheat,
mortarboard, quill_pen, tea_leaf, abacus, bow_arrow, horse, pagoda_temple. (Full recipes in the
research report; each is a few primitive calls.)

## Mapping: ordered regex rules (first match wins), keyed on invention key; per-domain fallback
Validated against the live 272 keys: 272/272 resolve, 0 fall back. Distribution: vial_flask 35, rifle 25,
seal_stamp 23, cannon 19, rail_track 14, coin_ingot 14, book_scroll 12, war_banner 9, sailing_ship 8, ...
One disambiguation: artillery_cartridges -> cannon (checked before the generic "cartridge"->rifle rule).
14 literal qing_tech_* mappings (kilns->kiln_flame, silk->loom_thread, tea->tea_leaf, grand_canal->
bridge_canal, siku->book_scroll, court_mathematics->abacus, eight_banners->war_banner, columbian_crops->
plough_wheat, variolation->vial_flask, manchu->bow_arrow, han->seal_stamp, mongol->horse, tibetan->
pagoda_temple, uyghur->plough_wheat). Per-domain fallback (defensive, 0 keys hit): military->war_banner,
civic->cogwheel, oratory->book_scroll, religious->quill_pen, qing->pagoda_temple.

## Implementation
Replace emblem() call in gen() with MOTIFS[MOTIF_MAP[key]](d, tint, c, r). MOTIF_MAP built by applying
the ordered regex table to each key (+ fallback dict). Everything else (canvas/disc/write_bgra8/
write_gfx/inject_overrides) untouched. Deterministic; re-runnable.

## Risk
- A motif must never crash on any 50x50 draw (guard coords). Validate all 272 render + valid DDS.
- Keep the domain tint so within-domain nodes still read as a family; motif carries the subject.
- No new keys/spriteTypes; the .gfx + icon_override injection are already correct from #118.
